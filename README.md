7-Segment Display Interfacing using Arduino & Proteus

## Project Overview

This project demonstrates the interfacing of a 7-Segment Display with an Arduino.
The circuit was designed and simulated using Proteus, while the Arduino program
was developed using Arduino IDE.

A 7-Segment Display consists of seven individual LED segments (A-G).
By controlling these segments in different combinations, numerical digits from
0 to 9 can be displayed.

##  Tools & Technologies

- Arduino
- Arduino IDE
- Proteus
- 7-Segment Display
- Digital Electronics

 Project Features

- 7-Segment Display interfacing with Arduino
- Individual segment control using digital pins
- Displaying numerical digits
- Proteus circuit simulation
- Arduino programming
